# EBazaar - E-Commerce Web Application

## Project Overview
EBazaar is a Java-based E-Commerce web application developed using JSP, Servlets, JDBC, and MySQL. The application allows users to log in, browse products, add items to the cart, and purchase products.

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- Eclipse IDE

## Features
- User Login
- Browse Products
- Add to Cart
- Purchase Products
- Database Connectivity

## Project Structure
```
EBazaar/
├── src/
├── webapp/
├── .project
├── .classpath
```

## How to Run
1. Clone the repository.
2. Import the project into Eclipse.
3. Configure Apache Tomcat.
4. Create the MySQL database.
5. Update database credentials in `DBConnect.java`.
6. Run the project on Tomcat.
7. Open:

```
http://localhost:8080/EBazaar/
```
